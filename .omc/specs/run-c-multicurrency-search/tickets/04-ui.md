# T4 UI（S5）
- blockedBy: [02, 03]

## 目标
新建合同表单币种下拉；列表/详情展示币种；跨类型搜索框 + 分组结果。

## 改动
- `client/index.html`：新建合同表单插币种 `<select name="currency">`（CNY/USD/EUR，默认 CNY）；合同列表表头加"币种"列；顶部（合同列表面板头）加搜索 `<input id="search-q">` + 按钮 + `<div id="search-results">`。
- `client/app.js`：表单序列化带 `currency`（复用既有 api 封装）；渲染列表/详情显示币种；搜索提交 → `GET /api/search?q=` → 分组渲染合同+相对方结果（各条点击可进详情），无结果提示。
- `client/app.css`：搜索框与结果区样式（沿用既有 token 变量）。

## 验收
- 手工冒烟（`node server/index.js` + 浏览器）：选 USD 建合同成功，列表/详情显示 USD；顶部搜索跨类型出结果分组。
- `node --test` 零回归（UI 不参与单测；由既有 smoke 校验服务面仍通）。

## Review gate
审查：币种下拉默认 CNY、提交带 currency、搜索分组渲染、结果经文本节点插入防 XSS。
